# Machine Learning Projects

This folder contains my beginner-level Machine Learning projects using Python.

## Projects

### 1. Student CGPA Prediction
- Algorithm: Linear Regression
- Input: Student Attendance
- Output: Predicted CGPA
- Libraries: Pandas, Matplotlib, Scikit-learn

## How to Run

1. Install the required libraries:
   `pip install pandas matplotlib scikit-learn`

2. Run the Python program:
   `python supervised_linear_regression.ipynb`

## Learning Goals
- Understand supervised learning.
- Train a Linear Regression model.
- Make predictions using student data.
- Visualize data and predictions.
